# 🚀 Project Vision: prd.md

## 📝 Vision
DevJournal is a premium "Build in Public" platform that transforms daily developer logs into an aesthetic, professional portfolio.

## 🎯 Target
Indie Hackers and Engineers who want to document their journey with a "deterministic" output that wows visitors.

## ✨ Key Features
- **Deterministic Portability:** Full JSON backup/restore at project and global levels.
- **Noir Aesthetic:** A high-end dark theme inspired by Vercel/Linear design systems.
- **Unified Log System:** Structured logging (Plan, Build, Reflect) to capture the full engineering lifecycle.
- **Mobile-Responsive Portfolio:** Automatically generated public pages for all active projects.

## 🛠️ Tech Stack
- Next.js 16 (Turbopack)
- Tailwind CSS (Noir Theme)
- Zustand (Local Persistence)
- Framer Motion

## 🏗️ Development (BLAST)
We build using **Blueprint, Link, Architect, Style, Trigger** to ensure code logic always precedes visual polish and that project memory remains persistent.
